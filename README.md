# kenedyducheine.github.io

My personal site, in the style of [azine](https://azine.io).

- **Edit the words or projects:** `index.html`. Each project is one
  `<article class="show">` block in the Projects section; copy one to add another.
- **Change the look:** the variables at the top of the `<style>` block in `index.html`.
- **Art:** `assets/art/`, public domain works from The Metropolitan Museum of Art's
  Open Access collection (the same ones that open azine.io).
- **Handwriting:** `assets/fonts/azine-hand.woff2`, the Azine Hand font.

GitHub Pages publishes the `main` branch automatically at https://kenedyducheine.github.io.
